# Seyitname - Personal Portfolio and Management System

This project is a personal web portfolio built with **ASP.NET Core 8.0 MVC** and **Entity Framework Core**, following an N-Layer Architecture.

## 🛠️ Technologies Used

* **Backend:** C#, .NET 8.0 MVC, ASP.NET Core Identity
* **Database:** SQLite / EF Core 8.0
* **Frontend:** HTML5, CSS3 (Custom Responsive & Animations), JavaScript
* **Tools & Productivity:** Git, GitHub Copilot (used as a productivity tool for UI and template development)

## ✨ Key Features

* **Identity Authentication:** User registration, login, and a role-based authorization system.
* **Dynamic Content:** Dynamic portfolio and contact form management through the database, powered by EF Core Migrations.
* **Modern Interface:** Custom CSS animations and a responsive layout design.

## 🚀 Running the Project Locally

1. Clone the repository: `git clone https://github.com/Seyitname/SeyitnameWebSite.git`
2. Navigate to the project directory: `cd SeyitnameWebSite`
3. Update the database: `dotnet ef database update`
4. Run the application: `dotnet run`
