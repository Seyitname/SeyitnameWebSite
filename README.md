# Seyitname – Personal Portfolio & Management System

🌐 **Live Demo:** [seyitname.vercel.app](https://seyitname.vercel.app)

<details open>
<summary><b>🇬🇧 English</b></summary>

A personal portfolio and contact platform built with **ASP.NET Core 8.0 MVC** and **Entity Framework Core**. The application follows an N-Layer Architecture to keep presentation, business, and data access concerns separated.

## Tech Stack

- **Backend:** C#, ASP.NET Core 8.0 MVC, ASP.NET Core Identity
- **Data Access:** Entity Framework Core 8.0 (code-first migrations), SQLite (development), PostgreSQL (production)
- **Frontend:** HTML5, CSS3 (responsive layout, custom animations), JavaScript
- **Deployment:** Vercel (containerized with Docker)

## Features

- User registration, authentication, and role-based authorization with ASP.NET Core Identity
- Database-driven portfolio and contact form management
- Multi-section public website, including portfolio, contact, information, and legal pages
- Responsive design with custom CSS animations

## Getting Started

```bash
git clone https://github.com/Seyitname/SeyitnameWebSite.git
cd SeyitnameWebSite
dotnet ef database update
dotnet run
```
